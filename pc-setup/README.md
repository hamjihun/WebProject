# 사내 PC 자동 셋팅 도구

새 PC나 포맷한 PC에서 **`Setup.bat` 더블클릭 한 번**으로 사내 표준 셋팅을 진행합니다.
설치파일은 USB(**프로그램USB**)의 `【 Application 】` 폴더에서 자동으로 찾습니다. USB 드라이브 문자(D:, E: 등)가 바뀌어도 됩니다.

## 진행 순서

| 순서 | 작업 | 내용 |
|---|---|---|
| 1 | 이더넷 IP 설정 | 수동 입력(IP / 서브넷 / 게이트웨이 / DNS 168.126.63.1) 또는 **자동으로 IP 받기(DHCP)** |
| 2 | 윈도우 업데이트 시작 | **백그라운드에서 시작**해서 아래 프로그램 설치와 동시에 진행 (선택적 업데이트의 드라이버 포함) |
| 3 | 프로그램 설치 | 오피스, 반디집, 크롬, 카카오톡, Adobe Reader, V3, ERP 를 **30초 간격으로 차례로 실행해 동시에 설치** + **OneDrive 삭제** (프로그램 추가/제거의 제거 명령 실행) |
| 4 | 폰트 설치 | `2. font\LG스마트체` 의 .ttf 파일을 설치 |
| 5 | 작업표시줄 | 뉴스 및 관심사 끄기, 검색은 아이콘만, **메일·Microsoft Store·반디집 아이콘 제거** |
| 6 | 바탕화면 아이콘 | 컴퓨터, 사용자 파일(문서), 네트워크, 휴지통, 제어판 |
| 7 | 오피스 바로가기 | 엑셀, 파워포인트, 워드 바로가기를 바탕화면에 |
| 8 | 파일 확장명 / UAC | 파일 확장명 표시, **사용자 계정 컨트롤 가장 아래(알리지 않음)** (+ PC 이름 변경, 입력한 경우만) |
| 9 | 전원 설정 | 화면 끄기 1시간, 절전 안 함, 노트북은 덮개를 닫아도 아무것도 안 함 |
| 10 | 시작화면 정리 | 고정된 항목을 모두 지우고 엣지만 고정 |
| 11 | 엣지 설정 | 홈 단추, 즐겨찾기 모음 항상, 다운로드 단추, 다운로드 전에 저장 위치 확인 |
| 12 | 크롬 설정 | 홈 버튼 표시, 북마크바 항상 표시 |
| 13 | 크롬·엣지 확장 | 크롬·엣지를 최신 버전으로 업데이트한 뒤 ClouDoc 확장프로그램 자동 설치 |
| 14 | 프린터 설치 | 체크한 프린터(부산 0.7 / 김해 2F 1.133 / 김해 1F 1.11)를 네트워크(IP) 프린터로 설치 |
| 15 | 윈도우 업데이트 확인 | 업데이트가 끝나기를 기다렸다가, 다시 시작이 필요하면 **설치 중인 프로그램이 없는지 확인 후 재부팅** → 로그인하면 이어서 업데이트 (최신 버전이 될 때까지 반복) |
| 16 | 문서중앙화 설치 | 재부팅하라고 뜨면 확인. 재부팅 후 남은 작업 자동 진행 |
| 17 | 정품 인증 확인 | 인증이 안 됐거나 Home 버전이면 끝날 때 안내 |

### 진행 상황 표시판
**셋팅 시작**을 누르면 왼쪽 작업 목록과 오른쪽 프로그램 목록이 진행 상황 표시판으로 바뀝니다. 로그를 읽지 않아도 색과 기호로 바로 확인할 수 있습니다.

| 표시 | 색 | 뜻 |
|---|---|---|
| `· 대기` | 회색 | 아직 시작 전 |
| `▶ 진행 중` | 파랑 | 진행 중 (자동 설치, 자동 진행, 삭제 중) |
| `! 직접 진행 필요` / `! [완료] 버튼을 눌러주세요` | 주황 | 설치 화면이나 노란 안내창을 보고 직접 진행 |
| `✔ 완료` / `✔ 이미 설치됨` | 초록 | 끝남 |
| `! 확인 필요` | 주황 | 끝났지만 경고가 있음 (로그 확인) |
| `✖ 실패` | 빨강 | 실패 (로그 확인) |
| `↻ 재부팅 후 계속` | 보라 | 재부팅 후 로그인하면 이어서 진행 |
| `■ 중지됨` | 회색 | 중지 버튼으로 멈춤 |

그룹 제목에 `완료 3 / 8` 처럼 완료 개수가 표시됩니다.
끝난 뒤 다시 실행하려면 **다시 선택** → 작업/프로그램 선택 → **셋팅 시작**.

### 동시 설치
- 프로그램은 30초 간격으로 하나씩 실행해서 **여러 개가 동시에** 설치됩니다. (간격은 `config.json` 의 `install.staggerSeconds`, 하나씩 설치하려면 `install.parallel` 을 `false`)
- 윈도우 설치 관리자는 MSI 설치를 한 번에 하나만 허용하기 때문에, 겹쳐서 실패한 프로그램(오류 1618)은 마지막에 하나씩 다시 설치합니다.
  자동 설치(크롬 등)가 실패한 경우도 마지막에 한 번 더 설치합니다.
- 자동 클릭은 각 설치 프로그램이 띄운 창에서만 동작하므로 다른 설치 창을 잘못 누르지 않습니다.
- 화면 아래 상태줄에 `프로그램 설치 중: ...  ‖  업데이트: ...` 로 두 작업의 진행 상황이 함께 표시됩니다.

### 중지
**중지** 버튼을 누르면 남은 작업을 멈추고 재부팅 후 이어하기 예약도 취소합니다.
이미 실행된 설치 창은 설치가 망가지지 않도록 강제로 끄지 않으니 필요하면 직접 닫아주세요.
다시 **셋팅 시작**을 누르면 이미 설치된 프로그램은 건너뜁니다.

`드라이버 확인 (제조사 도구 등)` 은 기본으로 꺼져 있습니다. (윈도우 업데이트에서 드라이버도 함께 설치합니다)

작업이 끝나면 **확인이 필요한 항목**(정품 인증, IP 충돌 등)을 모아서 보여줍니다.
모든 결과는 `logs\setup_PC이름_날짜.log` 에 저장됩니다.

## 사용 방법

1. `pc-setup` 폴더를 USB(프로그램USB)에 복사합니다. (USB 루트나 아무 폴더에 둬도 됩니다)
2. 셋팅할 PC에 USB를 꽂고 `Setup.bat` 을 더블클릭합니다. 관리자 권한 창에서 **예**.
3. 화면에서 입력합니다.
   - **이더넷 IP**: IP 를 입력하면 게이트웨이가 자동으로 바뀝니다. (`192.168.50.25` → `192.168.50.1`)
     자동으로 받으려면 **자동으로 IP 받기** 를 체크하세요.
   - **지점**: 부산 / 김해 선택. ERP 서버 주소가 정해지고, 부산은 부산 프린터가 자동 체크됩니다. 김해는 2F / 1F 를 직접 체크하세요.
   - **프로그램**: 오른쪽 목록에 각 프로그램의 설치파일 경로가 표시됩니다. `⚠ 설치파일을 찾지 못함` 이 있으면 해당 줄을 클릭하고 **설치파일 지정**으로 선택하세요. (한 번 지정하면 저장됩니다)
4. **셋팅 시작**을 누릅니다.

### 설치 안내창
직접 골라야 하는 것이 있는 설치(반디집, 카카오톡, ERP, 문서중앙화 등)는 화면 오른쪽 위에 **노란 안내창**이 떠서 할 일을 알려줍니다.

| 프로그램 | USB 설치파일 | 방식 |
|---|---|---|
| 오피스 | `1.OfficeSetup.exe` | 그대로 설치 진행 |
| 반디집 | `2.BANDIZIP-SETUP-STD-X64.EXE` | **자동 진행**: '새 버전 홈페이지 방문?' → 아니요 → '사용 통계 및 오류 보고서 자동 전송' 체크 해제 → 동의 및 설치 → 닫기 → 지금 적용 → 확인 |
| 크롬 | `3.ChromeSetup.exe` (USB 에 `*chrome*.msi` 오프라인 설치 파일이 있으면 그것을 먼저 사용) | 자동 설치. 실패하면 Google 공식 기업용 오프라인 설치 파일(msi)을 내려받아 다시 설치 |
| 카카오톡 | `4.KakaoTalk_Setup.exe` | **자동 진행**: 한국어 → OK → 다음 → 다음 → 'Daum을 시작페이지로 설정' 체크 해제 → 설치 → 설치 완료 화면 **마침** |
| Adobe Reader | `Reader_kr_install.exe` | 설치(인터넷으로 내려받음) 후 **자동 진행**: 마침 → PDF 기본 앱 'Adobe Acrobat' 선택 → 확인 → 열린 엣지 창 닫기 |
| V3 | `6.EPP_AgentSetup.exe` | 그대로 설치 진행 |
| ERP | `ERP_KSystem ...exe` (부산/김해 같은 프로그램) | **자동 진행**: 다음 → Finish → Client Update 에 지점 서버 주소 입력 → 다음 |
| 문서중앙화 | `8.문서중앙화.exe` | **자동 진행**: 다음 → 설치 → 마침 → 재부팅하라고 뜨면 **윈도우 업데이트/다른 설치가 끝났는지 확인한 뒤** 재부팅 |

**자동 진행 (반디집, 카카오톡, ERP)**: 설치 화면의 버튼·체크박스·입력칸을 프로그램이 직접 누르고 채웁니다.
체크 해제할 항목을 찾지 못하면 체크된 채로 설치되지 않도록 설치 버튼을 누르지 않고 멈춥니다. 진행 중에는 마우스/키보드를 건드리지 마세요.
화면을 찾지 못하면(버튼 이름이 다르거나 시간이 오래 걸리면) 자동으로 멈추고, 안내창을 보고 직접 진행한 뒤 **[완료]** 를 누르면 됩니다. 서버 주소는 클립보드에 복사되어 있습니다.

ERP 서버 주소: 부산 `192.168.0.252:8080` / 김해 `192.168.1.250:8080`
안내 문구는 `config.json` 의 각 프로그램 `guide` 에서 바꿀 수 있습니다.

### 재부팅과 이어하기
- 작업이 하나씩 진행될 때마다 **남은 작업을 저장**해 둡니다. 윈도우 업데이트·문서중앙화·다른 설치 프로그램·직접 재부팅 등 **어떤 이유로 재부팅되든** 같은 계정으로 로그인하면 프로그램이 자동으로 열리고 남은 작업부터 이어서 진행합니다.
- 자동 실행은 두 가지로 등록합니다: 작업 스케줄러(로그인 20초 뒤, PC 이름을 바꿔도 동작) + 로그인 시 한 번 실행되는 시작 항목(예비). 둘 다 실행돼도 프로그램은 하나만 뜹니다.
- 이어서 할 때 IP 설정은 다시 하지 않고, 이미 설치된 프로그램은 건너뜁니다. 윈도우 업데이트가 끝나지 않았으면 업데이트부터 다시 진행합니다.
- 윈도우 업데이트 후 재부팅이 필요하면, **설치 중인 프로그램이 없는지 확인한 뒤** 재부팅할지 물어봅니다. "최신 버전입니다" 가 될 때까지 반복합니다. (최대 6회)
- **USB 는 끝날 때까지 꽂아두세요.** (문서중앙화 설치파일이 USB 에 있습니다)
- 이어하기를 위해 도구가 `C:\ProgramData\PCSetup\app` 에 복사되고, 이후 로그는 그 안의 `logs` 폴더에 저장됩니다.
- 모든 작업이 끝나거나 **중지** 를 누르면 자동 실행 예약은 지워집니다.

## 처음 한 번 해두면 좋은 것

### USB 폴더 목록 보내기
**USB 폴더 목록 저장** 버튼을 누르면 `logs\usb_folder_list.txt` 에 USB 폴더 구조가 저장됩니다.
설치파일 이름에 맞춰 설정을 정확히 맞추고 싶을 때 이 파일을 공유해 주세요.

### 시작화면 (Windows 11)
Windows 11 은 시작화면을 프로그램으로 완벽하게 지우기가 어렵습니다.
한 PC에서 시작화면을 **엣지만 남기고 직접 정리**한 뒤 **시작화면 저장 (Win11)** 버튼을 누르면, 다음 PC부터는 그 배치가 그대로 자동 적용됩니다.
(Windows 10 은 저장 없이도 자동으로 엣지만 남깁니다.)

## config.json 주요 설정

| 항목 | 설명 |
|---|---|
| `usb.label` / `usb.appFolder` | USB 이름(`프로그램USB`)과 설치파일 폴더 이름(`【 Application 】`) |
| `network` | IP 칸의 기본값(`192.168.`), 서브넷, DNS |
| `sites` | 지점별 ERP 서버 주소와 자동 체크할 프린터 |
| `programs` | 설치할 프로그램 목록 (아래 참고). `uninstall` 이 있는 항목은 삭제 (예: `"uninstall": "*OneDrive*"`) |
| `fonts.folder` | 폰트 폴더 (`【 Application 】` 기준 경로) |
| `power` | 화면 끄기(분), 절전(0 = 안 함), 덮개 동작 |
| `browser` | 크롬/엣지 확장프로그램 ID. `enforceSettings` 가 `false` 면 직원이 나중에 설정을 바꿀 수 있음 |
| `printer` | 드라이버 폴더, 프린터 이름 앞부분, 프린터 목록(이름·IP) |
| `docCentral` | 문서중앙화 폴더 |

### 프로그램 항목

```json
{
  "name": "반디집",
  "find": ["*bandizip*.exe", "*반디집*.exe"],
  "args": "/S",
  "installed": ["%ProgramFiles%\\Bandizip\\Bandizip.exe"]
}
```

| 항목 | 설명 |
|---|---|
| `name` | 화면에 표시될 이름 |
| `find` | `【 Application 】` 안에서 설치파일을 찾을 패턴. 폴더 이름까지 포함해 비교합니다 (`*` = 아무 글자) |
| `path` | 설치파일 경로를 직접 지정 (화면의 **설치파일 지정** 버튼으로 자동 입력됨) |
| `args` | 자동 설치 옵션. 비워두면 설치 화면이 떠서 직접 진행 |
| `guide` | 설치하는 동안 안내창에 보여줄 문구 (`{erpServer}` 는 지점의 ERP 주소로 바뀜) |
| `confirmAfter` | `true` 면 설치 창이 닫힌 뒤에도 안내창의 [완료] 를 누를 때까지 기다림 |
| `clipboard` | 설치 시작 전에 클립보드에 복사할 내용 |
| `dismiss` | 설치 중에 보이면 언제든 바로 누를 버튼 (예: 반디집 `"아니요*"`, 카카오톡 `"마침*"`) |
| `argsMsi` | 설치 파일이 .msi 일 때 쓸 옵션 (`args` 는 .exe 용) |
| `fallbackUrl` | 자동 설치가 실패하면 이 주소에서 설치 파일을 내려받아 다시 설치 |
| `auto` | 설치 화면 자동 조작 단계. `click`(누를 버튼), `alsoClick`(그 전까지 계속 누를 버튼), `uncheck`(체크 해제할 항목), `radio`(선택할 라디오 버튼), `setText`(입력칸에 넣을 값), `select`(목록에서 고를 항목), `close`(창 닫기), `process`(다른 프로그램 창에서 찾기, 예: `OpenWith`, `msedge`), `windowText`(창 안 글자로 창 고르기), `waitIdle`(누르기 전에 업데이트/다른 설치 끝날 때까지 대기), `timeout`(초), `optional`(없어도 통과) |
| `installed` | 이 경로에 파일이 있으면 이미 설치된 것으로 보고 건너뜀 |

> 경로의 `\` 는 JSON 에서 `\\` 로 두 번 써야 합니다.

## 알아둘 점

- **직원 계정으로 로그인한 상태에서 실행하세요.** 재부팅 후 이어하기도 같은 계정으로 로그인해야 실행됩니다.
  작업표시줄, 바탕화면 아이콘, 시작화면, 확장명 표시는 실행한 계정에 적용됩니다.
- **ClouDoc 확장프로그램**은 회사 정책으로 설치되므로 크롬/엣지에 "조직에서 관리" 라고 표시되고, 직원이 삭제할 수 없습니다. 크롬/엣지를 열면 자동으로 설치됩니다.
- **엣지·크롬 설정**은 브라우저를 다시 열면 적용됩니다.
- **엣지 첫 실행 화면**(데이터 없이 시작 / Google 데이터 / 허용 안 함)은 프로그램 설치를 시작할 때 회사 정책으로 꺼두므로 뜨지 않습니다. (`browser.hideEdgeFirstRun`)
- **프린터 드라이버 이름**은 드라이버 파일에서 `C3060` 이 들어간 모델을 자동으로 고릅니다. 다른 모델이 잡히면 로그의 "드라이버 모델 목록"을 보고 `printer.driverName` 에 정확한 이름을 넣으세요.
- 회사 백신(V3 등)이 스크립트 실행을 막으면 `pc-setup` 폴더를 예외로 등록하세요.
