# 연말 경품 추첨 (event)

IMS 수집기(monitor/server.js)가 `http://192.168.0.9:15138/event` 로 이 폴더를 불러 씁니다. 모니터링과 같은 포트를 쓰지만 폴더는 따로입니다.

## 설치
1. GitHub ZIP 의 `event` 폴더를 IMS 서버의 `C:\ims\event` 에 복사 (monitor 폴더 **옆**)
2. `C:\ims\monitor\deploy\setup-collector.cmd` 를 관리자 권한으로 한 번 실행 (수집기 다시 시작)
3. 브라우저에서 `http://192.168.0.9:15138/event` → 오른쪽 아래 "진행자 로그인" (모니터링 admin 계정)

## 진행 순서
1. ⚙ 설정 → 명단 붙여 넣기 (`그룹,팀,이름,매수` — 엑셀 4열 복사 가능, 매수 1~4) → [명단 적용]
2. 1차·2차 탈락 장수(그룹별), 경품 목록(위에서부터 차례로 추첨), 발표 간격 → [설정 저장]
3. TV: 전체 화면(⛶) + 소리(🔊) → [1차 탈락 시작] → 끝나면 [2차 탈락 시작] → [🎁 다음 경품 추첨]
   - 스페이스: 멈춤/계속, H: 아래 버튼 숨기기
   - 리허설 뒤에는 설정 창의 [처음부터 다시] (명단·설정은 그대로)
4. 결과: 설정 창의 "결과 엑셀(CSV) 받기"

직원들은 같은 주소로 보기만 합니다 (휴대폰 가능, 이름·응모번호 찾기). 데이터는 `event/data/event.json`.
