# 🎁 연말 경품 추첨 프로그램

점심시간 TV 송출용 추첨 화면입니다. 응모권 1매씩 탈락자를 발표하고(1차 → 2차), 남은 응모권으로 최종 경품을 추첨합니다.

## 다운로드 · 설치 (Windows)
1. `dist/YearEndLottery.zip`을 내려받아 압축을 풉니다. (예: `C:\YearEndLottery`)
2. **`install.bat`** 을 더블클릭합니다. 실행 엔진(Node.js)을 자동으로 받아오고, 바탕화면에 **[연말 경품 추첨]** 바로가기를 만듭니다.
   - 우클릭 → 관리자 권한으로 실행하면 방화벽 포트도 자동으로 열립니다.
   - 인터넷이 막힌 PC라면 https://nodejs.org 에서 LTS를 직접 설치한 뒤 다시 실행하세요.
3. 바탕화면 **[연말 경품 추첨]** (또는 `start.bat`) 을 실행하면 서버가 켜지고, 진행자 화면이 브라우저에 자동으로 열립니다.

자세한 사용법은 압축 안의 `HOW_TO_USE.txt`를 보세요. Mac/Linux는 Node.js 18 이상을 설치한 뒤 `./start.sh`로 실행합니다.

| 용도 | 주소 (서버 창과 `접속주소.txt`에 표시) |
|---|---|
| 진행자 (추첨 조작, TV) | `http://localhost:3000/?host=비밀키` |
| 관람자 (전 직원, 실시간 시청) | `http://서버IP:3000/` |

- 진행자가 누르는 대로 모든 관람자 화면에 같은 애니메이션과 결과가 실시간으로 나옵니다.
- 관람자 화면에는 조작 버튼이 없습니다. 소리는 🔊 버튼을 눌러야 나옵니다(브라우저 정책).
- 진행 상황은 `state.json`에 저장되므로 서버를 재시작하거나 새로고침해도 이어서 진행됩니다.
- 비밀키·포트는 처음 실행할 때 만들어지는 `config.json`에 저장됩니다(`{"port":3000,"hostKey":"...","openBrowser":true}`).
- 서버 없이 TV 한 대만 쓸 때는 `index.html`을 크롬으로 바로 열어도 됩니다.
- 코드를 고친 뒤 배포 파일을 다시 만들려면 `python3 package-zip.py`를 실행합니다.

## 명단 등록 (엑셀)
⚙ 설정 → 엑셀 파일을 끌어놓거나 클릭해서 선택 → 확인 → **저장**

- `roster_template.xlsx`(명단 양식) 형식(그룹 / 근무처 / 부서 / 성명 / 응모권)을 권장합니다.
- 기존 원본 표(A·B 표가 좌우로 나란히 있고 NO…전체응모권…잔여응모권 열이 있는 형태)도 그대로 인식합니다. 이때는 왼쪽 표가 A, 오른쪽 표가 B가 됩니다.
- 등록하면 추첨 시작 전 화면 오른쪽에 팀별 전체 인원과 응모권(●)이 표시됩니다.

## 진행
- **스페이스바**: 시작 / 일시정지 / 다음 추첨 / 안내창 닫기 · **F**: 전체화면
- 상단에서 A그룹 / B그룹을 전환합니다(진행 중에는 전환할 수 없습니다).
- 속도(초/매): 6초 × 300매 = 약 30분입니다.
- 설정에서 1차·2차 탈락 수, 최종 경품 목록(위에서부터 순서대로 추첨), 1인 1경품 여부를 정합니다.
- 결과는 설정 → **결과 CSV 다운로드**로 저장합니다.
- 추첨은 브라우저의 암호학적 난수(`crypto.getRandomValues`)를 사용합니다.
