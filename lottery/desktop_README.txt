==========================================
  연말 경품 추첨 - 바로 실행 (서버 필요 없음)
==========================================

■ 설치
  압축을 풀어서 폴더를 원하는 곳에 둡니다. (예: 바탕화면 또는 C:\YearEndLottery)
  ims / 서버 / 인터넷 설치 필요 없습니다.

■ 실행
  START.bat 더블클릭 → 크롬으로 추첨 화면이 열립니다.
  (크롬이 없으면 기본 브라우저로 열림. index.html 을 크롬으로 직접 열어도 같습니다)

■ 진행
  1. 왼쪽 패널 [📂 명단 등록 · 설정] → 명단 엑셀을 끌어놓기 → [저장]
  2. [▶ 탈락자 발표 시작] (또는 스페이스바) : 처음 = 1차, 다시 누르면 = 2차
  3. 2차가 끝나면 [🏆 경품 추첨], A·B 모두 끝나면 [🥇 1등 통합 추첨]
  - H : 왼쪽 패널 숨기기 · F : 전체화면
  - 식당 TV(두 번째 모니터) : [📺 현황판 새 창으로 열기] → 그 창을 TV 쪽으로 옮기고 F

■ 꼭 지켜주세요
  - 진행 기록은 이 PC의 크롬에 저장됩니다. 1차·2차·최종 모두 같은 PC에서 START.bat 으로 여세요.
    (시크릿 창 X, 크롬 방문 기록/쿠키 삭제 X)
  - 매번 끝나면 ⚙설정 → [💾 진행 백업 저장] 으로 백업 파일을 받아두세요.
    문제가 생기면 [📂 백업 불러오기] 로 그대로 이어서 할 수 있습니다.
