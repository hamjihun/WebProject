========================================
  연말 경품 추첨 프로그램 - 설치 / 사용법
========================================

■ 설치 (Windows, 처음 한 번만)
  1. 압축을 풉니다. (경로는 짧고 영문이면 좋습니다. 예: C:\YearEndLottery)
  2. config.json 을 메모장으로 열어 관리자 비밀번호를 정합니다. (없으면 처음 실행 때 자동 생성)
       { "port": 15138, "basePath": "/event", "adminUser": "admin", "adminPassword": "비밀번호" }
     → 서버를 처음 켤 때 비밀번호는 암호화된 값(adminPasswordHash)으로 바뀌어 저장됩니다.
  3. install.bat 을 더블클릭합니다.
     - 실행 엔진(Node.js)을 자동으로 내려받고, 바탕화면에 [연말 경품 추첨] 바로가기를 만듭니다.
     - 우클릭 → [관리자 권한으로 실행]하면 방화벽도 열어줍니다.

■ 실행
  1. 바탕화면 [연말 경품 추첨] (또는 start.bat) 을 더블클릭합니다. 서버 창을 닫으면 꺼집니다.
  2. 접속 주소 (서버 창과 [접속주소.txt]에도 표시)
       - 전 직원 / 식당 TV : http://서버IP:15138/event/
       - 식당 TV 현황판      : http://서버IP:15138/event/?view=board
  3. 관리자 : 화면 오른쪽 위 [🔒 관리자] → admin / 비밀번호 로 로그인 → 왼쪽 진행 패널이 나타납니다.
     관리자가 아닌 접속자는 시청만 가능합니다. (조작 버튼 없음)

■ 15138 포트를 이미 다른 시스템(서버 모니터링 등)이 쓰고 있다면
  한 포트는 한 프로그램만 쓸 수 있습니다. 둘 중 하나로 하세요.
  A) 기존 시스템이 /event 요청을 이 프로그램으로 넘겨주게(프록시) 설정
       - config.json : "port": 3000, "host": "127.0.0.1"   (이 PC 안에서만 받음, 방화벽 불필요)
       - 기존 시스템 : /event/ 로 시작하는 요청을 http://127.0.0.1:3000 으로 그대로 전달
                      (/event/api/events 는 실시간 스트림이므로 버퍼링·시간제한 없이 전달)
  B) 이 프로그램은 다른 포트(예: 3000)로 열고 그 주소를 공유

■ 진행 (관리자)
  - 왼쪽 패널 [▶ 탈락자 발표 시작] : 처음 누르면 1차, 끝나고 다시 누르면 2차 탈락이 진행·저장됩니다.
  - 스페이스바 : 시작 / 일시정지 / 다음 추첨 · H : 왼쪽 패널 숨기기 · F : 전체화면
  - 2차가 끝나면 같은 버튼이 [🏆 경품 추첨]으로 바뀌고, A·B 모두 끝나면 [🥇 1등 통합 추첨]이 됩니다.
  - 진행 기록은 자동 저장되어 다음날 다시 켜도 이어서 진행됩니다.

■ 공정성 기록
  - 화면에 현재 날짜·시각이 표시되고, 탈락/당첨마다 시각이 함께 나옵니다.
  - [📜 추첨 로그] : 명단 등록, 발표 시작·종료, 1매 탈락, 당첨, 설정 변경, 초기화가 초 단위로 기록됩니다.
    해시 체인으로 묶여 있어 중간 기록을 고치면 [무결성 확인]에서 드러납니다.
  - 서버 PC의 logs 폴더에 날짜별 로그(audit-날짜.jsonl)와 관리자 로그인 기록(admin-access.log)이 남습니다.

■ 문제 해결
  - "포트를 이미 사용 중" : 위의 15138 포트 안내를 보세요.
  - 다른 PC에서 접속 안 됨 : 방화벽 허용 여부, 같은 사내망인지, IP 주소가 맞는지 확인하세요.
  - 비밀번호 변경 : 서버를 끄고 config.json 에 "adminPassword": "새 비밀번호" 를 넣고 다시 켜세요.
