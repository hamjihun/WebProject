========================================
  연말 경품 추첨 프로그램 - 설치 / 사용법
========================================

■ 설치 (Windows, 처음 한 번만)
  1. 압축을 풉니다. (경로는 짧고 영문이면 좋습니다. 예: C:\YearEndLottery)
  2. install.bat 을 더블클릭합니다.
     - 실행 엔진(Node.js)을 자동으로 내려받고, 바탕화면에 [연말 경품 추첨] 바로가기를 만듭니다.
     - 우클릭 → [관리자 권한으로 실행]하면 방화벽도 자동으로 열어줍니다.
     - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.

■ 실행
  1. 바탕화면 [연말 경품 추첨] (또는 start.bat) 을 더블클릭합니다.
  2. 검은 서버 창이 열리고, 진행자 화면이 브라우저에 자동으로 열립니다.
     ※ 서버 창을 닫으면 추첨 서버가 꺼집니다. 추첨이 끝날 때까지 켜두세요.
  3. 접속 주소는 서버 창과 [접속주소.txt] 파일에 나옵니다.
       - 진행자(TV) : http://localhost:3000/?host=비밀키   ← 외부 공유 금지
       - 전 직원    : http://서버PC의IP:3000/              ← 사내 메신저로 공유
  4. 처음 실행 때 Windows 방화벽 경고가 나오면 [액세스 허용]을 누르세요.

■ 명단 등록
  진행자 화면 → [엑셀로 명단 등록] 또는 ⚙ → 엑셀 파일을 끌어놓기 → [저장]
  - 양식: roster_template.xlsx (그룹 / 근무처 / 부서 / 성명 / 응모권)
  - 기존 A·B 좌우 표 형태도 그대로 인식합니다.

■ 진행
  - 스페이스바 : 시작 / 일시정지 / 다음 추첨 / 안내창 닫기
  - F          : 전체화면
  - ⚙ 설정     : 1차·2차 탈락 수, 경품 목록, 결과 CSV 다운로드, 초기화

■ 설정 파일 (config.json, 처음 실행 시 자동 생성)
  { "port": 3000, "hostKey": "진행자 비밀키", "openBrowser": true }
  - 비밀키나 포트를 바꾸려면 서버를 끄고 메모장으로 고친 뒤 다시 실행하세요.

■ 서버 없이 TV 한 대만 쓸 때
  index.html 을 크롬/엣지로 바로 열어도 됩니다. (진행 상황은 그 브라우저에 저장)

■ 문제 해결
  - "포트를 이미 사용 중" : 서버가 이미 켜져 있습니다. 기존 창을 쓰거나 config.json 의 port 를 바꾸세요.
  - 다른 PC에서 접속 안 됨 : 방화벽 허용 여부, 같은 사내망인지, IP 주소가 맞는지 확인하세요.
  - 처음부터 다시 하려면   : ⚙ → [전체 기본값 복원] (또는 서버를 끄고 state.json 파일 삭제)
