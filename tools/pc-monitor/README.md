# PC 모니터 (팬 소음 / 멈춤 원인 추적용)

설치할 필요가 없습니다. Windows에 기본으로 들어 있는 PowerShell로 동작합니다.
일정 간격(기본 10초)마다 PC 상태를 파일에 기록하고, 문제가 생긴 시점에는 자세한 내용을 따로 남깁니다.

## 파일 구성
| 파일 | 용도 |
|---|---|
| `start-monitor.bat` | 창을 띄워 실시간으로 보면서 기록합니다. 처음 확인할 때 쓰세요. |
| `start-monitor-background.bat` | 창 없이 백그라운드에서 기록합니다. 평소에는 이것을 쓰세요. |
| `stop-monitor.bat` | 백그라운드 기록을 중지합니다. |
| `pc-monitor.ps1` | 실제 모니터링 스크립트입니다. |

네 파일을 같은 폴더(예: `C:\PCMonitor\`)에 넣고 실행하세요.

## 기록 위치
`문서\PCMonitor\`
- `monitor_날짜.csv`: 10초마다 한 줄씩 기록되며 엑셀로 바로 열립니다.
  - 기록 항목: 시간, CPU%, CPU 클럭, 메모리%, 디스크%, C드라이브 여유 공간, 전원(AC/배터리), CPU 상위 프로세스, 비고
- `alert_날짜.log`: 아래 상황에서만 상위 프로세스 10개를 자세히 남깁니다.
  - **CPU 높음**: 80% 이상
  - **메모리 부족**: 90% 이상
  - **디스크 포화**: 90% 이상
  - **클럭 저하**: CPU 부하가 높은데도 클럭이 기본값의 50% 미만일 때. 발열이나 절전으로 성능이 제한(스로틀링)됐을 가능성이 있습니다.
  - **기록 지연**: 10초마다 돌아야 할 기록이 30초 이상 밀렸을 때. 그 사이에 PC가 멈췄거나 절전 모드였다는 뜻입니다.
- 14일이 지난 파일은 자동으로 삭제됩니다.

## 부팅할 때 자동 실행 (권장)
1. `Win + R` → `shell:startup` 입력 → Enter
2. 열린 폴더에 `start-monitor-background.bat`의 **바로 가기**를 넣습니다.
   - 파일에서 오른쪽 클릭 → 바로 가기 만들기 → 만든 바로 가기를 그 폴더로 이동

## 확인 방법
1. 멈추거나 팬이 크게 돌았던 **시간을 대략 메모**해 둡니다.
2. 그날 `alert_날짜.log`에서 그 시간대를 찾습니다.
3. 반복해서 위에 나오는 프로세스가 원인 후보입니다.

## 참고
- PC 부담은 거의 없습니다(10초에 한 번, 1초 미만 실행).
- 온도는 관리자 권한이 있고 제조사가 지원할 때만 기록됩니다. 대부분은 공란으로 나옵니다.
- 회사 보안 정책 때문에 PowerShell 실행이 막혀 있으면 실행되지 않습니다. 이때는 전산팀에 문의하세요.
- 간격이나 기준값을 바꾸려면 bat 파일의 마지막 부분에 옵션을 붙이세요. 예: `-IntervalSec 5 -CpuAlert 70`
