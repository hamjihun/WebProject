# PC 모니터 (exe)

PC 상태를 계속 기록하다가 **프로그램이 '응답 없음'으로 멈추면 그 순간을 자동으로 감지**해서 원인을 분석해 남기는 프로그램입니다.

- 실행 파일: `dist/PCMonitor.exe` (약 50KB, 설치 불필요)
- 실행 조건: Windows 10/11 64비트. 기본 탑재된 .NET Framework 4.8을 사용합니다.

## 사용법
1. `PCMonitor.exe`를 고정 위치에 둡니다. 예: `C:\PCMonitor\PCMonitor.exe`
   (자동 실행이 이 경로로 등록되므로 바탕화면이나 다운로드 폴더는 피하세요.)
2. 실행하면 화면 오른쪽 아래 알림 영역(시계 옆 `^`)에 아이콘이 생깁니다.
   - 초록: 정상 / 노랑: 주의 / 빨강: 응답 없음 또는 과부하
3. 처음 실행할 때 물어보는 항목
   - **Windows 시작 시 자동 실행**: '예'를 권장합니다.
   - **ERP 이름 설정**: `settings.ini` 파일의 `ErpProcess=` 뒤에 작업 관리자 → 세부 정보 탭에 보이는 ERP 이름을 적습니다.

## 아이콘 우클릭 메뉴
| 메뉴 | 내용 |
|---|---|
| 현재 상태 보기 | CPU·메모리·디스크 사용량과 많이 쓰는 프로그램 순위 (아이콘 더블클릭과 같음) |
| 멈춤 기록 보기 (엑셀) | 지금까지 멈춘 기록 목록 (`멈춤기록.csv`) |
| 오늘 상세 분석 보기 | 멈춘 순간의 상세 분석 (`분석_날짜.log`) |
| 기록 폴더 열기 | `문서\PCMonitor` 폴더 열기 |

## 멈춤 원인 판정
프로그램이 '응답 없음'이 되는 순간을 2초 간격으로 확인하고, 그 시점과 직전 1분의 상태를 함께 분석합니다.

| 원인 분류 | 판정 기준 |
|---|---|
| PC CPU 과부하 | 다른 프로그램(백신·업데이트 등)이 CPU를 점유함. 원인 프로그램 이름을 함께 기록 |
| 프로그램 자체 과부하/처리 중 | 멈춘 프로그램 자신이 CPU를 많이 사용함 (대량 조회·출력 등) |
| 메모리 부족 | 메모리 90% 이상. 많이 쓰는 프로그램을 함께 기록 |
| 디스크 병목 | 디스크 사용률 90% 이상. 디스크를 많이 쓰는 프로그램을 함께 기록 |
| 발열/절전 성능제한 | 부하가 있는데 CPU 클럭이 기본의 50% 미만으로 떨어짐 |
| 서버 연결 실패 / 네트워크 지연 | 멈춘 프로그램이 연결 중인 서버에 ping과 접속을 시도해 응답 시간을 측정 |
| 서버 응답 대기 추정 | PC와 네트워크는 정상 → 서버(DB) 처리 지연으로 추정 |
| PC 전체 멈춤 | 이 모니터 자체도 멈춤 → 특정 프로그램이 아니라 PC나 드라이버 문제 |

## 기록 파일 (`문서\PCMonitor`)
- `멈춤기록.csv`: 멈춤 한 건당 한 줄 (날짜, 시작/끝 시간, 멈춘 시간, 프로그램, 원인, 판정)
- `분석_날짜.log`: 멈춤마다 판정 근거, 상위 프로그램, 서버 응답 시간, 직전 1분 기록
- `monitor_날짜.csv`: 10초마다 기록한 전체 상태
- 30일이 지난 파일은 자동으로 삭제됩니다. 설정은 `settings.ini`에서 바꿀 수 있습니다.

## 참고
- 서명되지 않은 exe라 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다. 이때 '추가 정보' → '실행'을 누르세요.
- 회사 보안 프로그램이 실행을 차단하면 전산팀에 허용을 요청하세요.
- 온도는 기록하지 않습니다(일반 권한으로는 읽을 수 없음). 대신 CPU 클럭 저하로 발열을 판단합니다.

## 다시 빌드하기
```bash
dotnet build -c Release
```
.NET SDK 8에서 `net48` 대상으로 빌드합니다. Linux에서도 빌드할 수 있습니다.
