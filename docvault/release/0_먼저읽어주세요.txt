==========================================================
  DocVault 문서중앙화 - 설치 파일 안내
==========================================================

[폴더 안내]

  1_서버설치      문서중앙화 서버 PC에 설치합니다. (회사에 1대, 한 번만)
  2_직원PC설치    직원 PC마다 설치합니다.
  3_관리자참고    자세한 설명서 (README.md)


[처음 설치하는 순서]

  1. 서버 PC
     - "1_서버설치" 폴더를 통째로 C:\DocVault 로 복사합니다.
     - 자세한 방법: 1_서버설치\서버설치방법.txt

  2. 관리자 설정 (서버 PC 또는 아무 PC의 브라우저)
     - http://서버IP:8080 접속
     - 아이디 admin / 비밀번호는 C:\DocVault\data\초기관리자비밀번호.txt
     - 그룹(팀) → 사용자 → 드라이브·권한 순서로 만듭니다.

  3. 직원 PC
     - 자세한 방법: 2_직원PC설치\직원PC설치방법.txt


[업데이트할 때 (새 버전을 받았을 때)]

  서버 PC
    1. 서버를 멈춥니다. (서비스로 설치했다면 "서비스중지.bat")
    2. 아래 두 파일만 C:\DocVault 에 덮어씁니다.
         docvault-server.exe
         downloads\docvault-setup.exe
       ※ data 폴더와 docvault.json 은 절대 덮어쓰거나 지우지 마세요.
          (계정, 권한, 파일 목록이 모두 data 폴더에 있습니다)
    3. 서버를 다시 시작합니다.

  직원 PC
    - 새 설치 파일을 다시 실행하면 덮어서 설치됩니다.
