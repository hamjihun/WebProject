==========================================================
  2. 직원 PC 설치 방법
==========================================================

[방법 A - 웹에서 받기 (추천)]

  1. 직원 PC의 브라우저로 http://서버IP:8080 접속
  2. 로그인 화면 아래 [PC 프로그램 설치] 클릭 → 받은 파일 실행
     (서버 주소가 자동으로 들어 있습니다)

[방법 B - 이 폴더의 파일로 설치 (USB, 공유폴더 등)]

  1. "DocVault_PC설치.exe" 실행
  2. 서버 주소를 물어보면 입력 (예: 192.168.50.10:8080)


[설치할 때]

  - "이 앱이 디바이스를 변경하도록 허용하시겠어요?" → [예]
    (PC 관리자 권한이 필요합니다)
  - "Windows의 PC 보호" 창이 뜨면 → [추가 정보] → [실행]
  - 설치가 끝나면 로그인 창이 뜹니다 → 아이디/비밀번호 입력
  - 잠시 후 [내 PC]에 문서 드라이브(F:, O: ...)가 나타납니다.


[사용]

  - 작업 표시줄 오른쪽 아래 DocVault 아이콘을 누르면
    연결 상태, 웹 문서함 열기, 버전 정보, 로그아웃 메뉴가 있습니다.
  - Windows를 켜면 자동으로 연결됩니다.


[제거]

  Windows [설정 → 앱 및 기능 → DocVault 문서 드라이브 → 제거]
