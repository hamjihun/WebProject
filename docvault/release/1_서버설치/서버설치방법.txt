==========================================================
  1. 서버 설치 방법 (서버 PC에서 한 번만)
==========================================================

[이 폴더의 파일]

  docvault-server.exe            서버 프로그램 (웹 화면 포함)
  docvault.json                  설정 파일 (저장 위치, 포트)
  downloads\docvault-setup.exe   직원 PC 설치 파일 (직원이 웹에서 받아 감. 그대로 두세요)
  윈도우서비스로설치.bat          서버 설치 (부팅하면 자동으로 실행)
  서비스중지.bat / 서비스시작.bat  서비스 멈춤 / 다시 시작 (업데이트할 때)
  윈도우서비스제거.bat            서비스 등록 해제 (데이터는 남음)
  방화벽열기.bat                  다른 PC가 접속할 수 있게 8080 포트 열기


[설치 순서]

  1. 이 폴더(1_서버설치)를 통째로 C:\DocVault 로 복사합니다.
     → C:\DocVault\docvault-server.exe 가 되도록

  2. 파일 저장 위치와 NAS 계정 입력 (docvault.json 을 메모장으로 열기)
       "store_dir": "\\192.168.50.201\DocVaultStore",
       "store_user": "NAS 아이디",
       "store_password": "NAS 비밀번호",
     - store_dir: NAS 공유폴더 주소를 탐색기 주소창에 쓰는 것과 똑같이 적습니다.
     - store_user / store_password: DocVaultStore 폴더에 읽기/쓰기 권한이 있는 NAS 계정
       (서비스는 Windows 시스템 계정으로 실행되므로, 탐색기에 저장한 비밀번호를 쓰지 못합니다.
        그래서 여기에 적어 주어야 합니다)
     - 비밀번호에 큰따옴표(")가 있으면 안 됩니다.
     - NAS 대신 이 PC에 저장하려면 store_dir 줄을 지웁니다. (C:\DocVault\store 에 저장)

  3. "방화벽열기.bat" → 마우스 오른쪽 → [관리자 권한으로 실행]

  4. 서버 설치
     - "윈도우서비스로설치.bat" → 마우스 오른쪽 → [관리자 권한으로 실행]
     - 창에 "✅ 서버가 정상적으로 실행 중입니다" 가 나오면 성공입니다.
     - 실패하면 창에 원인이 나옵니다. (같은 내용이 시작오류.txt 에도 저장됨)
       docvault.json 을 고친 뒤 "서비스시작.bat" (관리자 권한) 으로 다시 시작하세요.
     - 창을 띄우지 않고 백그라운드로 실행되며, PC를 켜면 자동으로 시작됩니다.

  5. 브라우저에서 http://localhost:8080 접속
     - 아이디: admin
     - 비밀번호: C:\DocVault\data\초기관리자비밀번호.txt 파일에 있습니다.
     - 로그인 후 [관리자 → 사용자]에서 admin 비밀번호를 바꾸고 이 txt 파일은 지우세요.


[설치 후 생기는 폴더 - 지우지 마세요]

  C:\DocVault\data      DB (계정, 권한, 폴더 구조, 버전, 로그)  ← 가장 중요, 백업 대상
  C:\DocVault\logs      서비스 실행 로그
  NAS 또는 store 폴더    파일 내용 (이름 없는 파일들)          ← 백업 대상


[문제가 생기면]

  - 서버 창이 바로 꺼짐: C:\DocVault\시작오류.txt 를 확인하세요.
  - admin 비밀번호 분실: 명령 프롬프트에서
      cd C:\DocVault
      docvault-server.exe reset-password admin 새비밀번호1234
