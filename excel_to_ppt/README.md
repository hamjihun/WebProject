# 엑셀 → 월간 경영실적 PPT 자동 반영 프로그램

매월 손익 엑셀 자료를 기준으로 **월간 경영실적 PPT의 표·차트·월 표기를 자동으로 채워 주는** 프로그램입니다.
지난달 PPT 파일을 그대로 기준 파일로 쓰면 되므로 별도의 템플릿 관리가 필요 없습니다.

## 1. 준비 (최초 1회)

### 방법 A. 실행 파일(exe) 로 쓰기 — Python 설치 불필요 (권장)

1. GitHub 저장소의 **Actions** 탭 → "Build Windows exe" → 가장 최근 실행 → 아래 **Artifacts** 의 `MonthlyPPT-windows` 클릭해 zip 내려받기
   (코드를 올릴 때마다 자동으로 새 exe 가 만들어집니다)
2. 압축을 풀면 `MonthlyPPT.exe`, `mapping.json`, `README.md` 세 파일이 나옵니다. **세 파일을 같은 폴더**에 두세요.
3. `MonthlyPPT.exe` 더블클릭. 바탕화면에 두려면 exe 를 마우스 오른쪽 → "바로 가기 만들기" 로 바로 가기를 만드세요.
   - 처음 실행할 때 Windows 의 "PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** 을 누르면 됩니다(서명 없는 프로그램이라 나오는 안내).
   - 첫 실행은 압축을 푸느라 몇 초 걸립니다.

### 방법 B. Python 으로 쓰기

1. Python 3.9 이상 설치 (https://www.python.org/downloads/ → 설치 시 **"Add python.exe to PATH"** 체크)
2. 이 폴더(`excel_to_ppt`)를 PC의 원하는 위치에 복사
3. `실행.bat` 더블클릭 → 필요한 라이브러리(openpyxl, python-pptx, tkinterdnd2)가 자동 설치됩니다.

Python 이 있는 PC 에서 직접 exe 를 만들려면 `build_exe.bat` 을 더블클릭하세요. `dist\MonthlyPPT.exe` 가 만들어집니다.

## 2. 매월 사용 방법

### 화면 프로그램 (권장)
1. `MonthlyPPT.exe` 더블클릭 (Python 으로 쓰는 경우 `실행.bat` 또는 `python gui.py`)
2. **손익 엑셀 파일**과 **지난달 PPT** 를 창 안의 상자에 끌어다 놓습니다. (상자를 클릭해서 골라도 됩니다. 두 파일을 한꺼번에 창 아무 곳에나 놓아도 확장자로 알아서 구분합니다.) 파일을 읽는 동안 상자에 "읽는 중…" 이 표시되고, 잘못 넣었으면 상자 오른쪽 위 ✕ 로 뺄 수 있습니다.
3. 엑셀을 놓으면 `N월 누적` 머리글을 읽어 **마감 월**이 자동으로 채워지고, 저장 파일 이름은 `기준PPT이름_N월.pptx` 로 제안됩니다.
   - 마감 월 = 실적이 확정된 달. 엑셀에 그 다음 달 값(예상치)이 있으면 표에는 `(괄호)`, 차트에는 점선으로 들어가고, 제목과 "누적" 머리글의 월도 이 값으로 바뀝니다.
4. **[▶ PPT 만들기]** 클릭
5. 결과가 화면에 나타납니다.
   - 초록 배너 **"완료! PPT 를 만들었습니다."** + [폴더 열기] 버튼 → 성공
   - 빨간 배너 **"실패: PPT 를 만들지 못했습니다."** + 원인 → 실패. 아래 "처리 내용" 창에 자세한 내용이 있습니다.
   - 성공했더라도 경고가 있으면 배너에 건수가 표시되니 처리 내용을 확인하세요.

### 명령줄
```
python update_ppt.py --excel "26년 8월 손익.xlsx" --ppt "7월 경영실적.pptx" --month 8 --out "8월 경영실적.pptx"
```
`--month` 를 생략하면 엑셀의 `N월 누적` 머리글에서 자동 인식하고, `--out` 을 생략하면 기준 PPT 옆에 `_N월.pptx` 로 저장합니다.

### 실행 전 엑셀에서 확인할 것
- 엑셀은 **엑셀 프로그램에서 저장된 파일**이어야 합니다(수식 계산 값이 파일에 저장돼 있어야 함). 다른 프로그램이 만든 파일이면 엑셀에서 한 번 열어 저장하세요.
- 각 시트의 `N월 누적` 머리글과 누적 수식 범위(예: `=SUM(E18:L18)`)를 당월에 맞게 고쳐 두세요. PPT 누적 열은 이 값을 그대로 가져옵니다.
- 당월 다음 달 예상치가 있으면 실적 행에 그대로 입력해 두면 PPT에 `(1,787)` 처럼 괄호로, 차트에는 점선으로 표시됩니다.

## 3. 자동으로 처리되는 것

| 슬라이드 | 자료 출처(엑셀 시트) | 내용 |
|---|---|---|
| 1 사업부별 손익표 | `그래프양식` E7:N27 | 표 전체(21행 x 10열)를 그대로 복사 |
| 2 일산 전체 | `매출액, 영업이익` | 매출액·영업이익 표 + 차트 2개 |
| 3 Insulation | `Insulation` | 매출액·재료비율·영업이익 표 + 차트 3개 |
| 4 유전체필터 | `유전체필터` | 위와 동일 |
| 5 탈취필터 | `탈취필터` | 위와 동일 |
| 6 밀레니얼 | `밀레니얼` | 위와 동일 |
| 7 노무비 | `인슐,유전체 노무비` | Insulation·유전체 노무비 표 + 차트 2개 |
| 8 노무비 | `탈취필터,밀레니얼 노무비` | 탈취필터·밀레니얼 노무비 표 + 차트 2개 |
| 9 누적 요약 | `누적 …` 시트 (G2 셀에 "N월 누적 실적" 문구가 있는 시트를 자동으로 찾음) | 매출~세전이익 7개 표 (억 단위, 비율, ↑↓ 증감) |
| 10 재고금액 | `26년꺼` | 재고 표 + 차트 |
| 공통 | | 제목·표 머리글의 "N월 경영실적", "N월 누적" 월 숫자 |

- **차트(19개 전부)** 는 PPT 차트가 참조하는 엑셀 셀 주소(예: `Insulation!$E$18:$P$18`)를 읽어 값을 갱신하므로 별도 설정이 없습니다.
- **예상치** : 당월 다음 달 값이 엑셀에 있으면 표는 `(1,787)` 처럼 괄호, 차트의 실적선은 점선. 그 이후 달은 빈칸.
- **숫자 서식** : 금액 백만 단위 정수(`1,990`), 비율 소수 1자리(`97.4%`), 슬라이드 2~8 표의 음수는 빨간 글씨.
- **26년 실적/증감 행의 연간 "누적" 칸** 은 원본 관례대로 비워 두고, "N월 누적" 칸만 채웁니다. (표 설정에 `"show_year_total": true` 를 넣으면 엑셀 값을 표시)

## 4. 직접 입력해야 하는 것 (엑셀에 없는 자료)

실행이 끝나면 로그에도 같은 목록이 출력됩니다.

- 슬라이드 2~6 : 오른쪽 코멘트 상자 (자작 금액, 판가/매입가 인상 요인 등)
- 슬라이드 9 : 오른쪽 "상세 Review" 코멘트
- 연초 : 표의 `24년/25년` 같은 연도 라벨은 바꾸지 않으므로 1월에 한 번 확인

## 5. 검증 결과와 알아 둘 점

7월 마감 엑셀(15개 시트)과 7월 PPT 로 실행해 슬라이드 1~10 의 표·차트 값을 원본과 대조했습니다.
차이는 원본 PPT 에 손으로 입력하면서 생긴 반올림 차이(134 → 135 등)와 옛 수치 몇 개뿐입니다.

- **슬라이드 2 영업이익 표의 "N월 누적" 열(26년 실적·달성율·전년대비)** 은 엑셀 `매출액, 영업이익` 시트 R열 수식(월별 합계) 값을 씁니다. 원본 PPT 에는 누계 파일 값(예: 1,547)이 들어 있어 엑셀 R열(1,619)과 다릅니다. 누계 파일 값을 쓰려면 엑셀 R열에 그 값을 넣어 두세요.
- **슬라이드 9** 는 누적 시트를 시트 이름이 아니라 G2 셀의 "26년 N월 누적 실적" 문구로 찾습니다. 시트 이름을 매달 바꿔도 되지만, G2 머리글을 당월로 고쳐 두어야 합니다. 못 찾으면 경고를 내고 `mapping.json` 의 `sheet` 이름을 씁니다.
- 슬라이드 6 재료비율 표처럼 한 칸에 두 줄(`73.7%` 와 `(76.5%)`)을 손으로 적어 둔 곳은 엑셀 값 한 줄로 바뀝니다.
- 엑셀은 **엑셀 프로그램에서 저장된 파일**이어야 합니다(수식 계산 값 필요). 외부 파일(부분별손익)에 연결된 `그래프양식` 시트는 그 파일을 연 상태에서 재계산·저장해 두세요.

## 6. mapping.json 고치는 법

표 하나가 아래 한 덩어리입니다.

```json
{
  "_설명": "슬라이드 3 : Insulation 매출액",
  "slide": 3, "shape": "표 9", "sheet": "Insulation", "month_col": "E",
  "rows": [
    {"ppt_row": 1, "excel_row": 16, "kind": "fixed"},
    {"ppt_row": 2, "excel_row": 17, "kind": "fixed",  "label": "목표"},
    {"ppt_row": 3, "excel_row": 18, "kind": "actual", "label": "실적"},
    {"ppt_row": 4, "excel_row": 19, "kind": "actual", "label": "달성"},
    {"ppt_row": 5, "excel_row": 20, "kind": "diff",   "label": "전년대비"}
  ]
}
```

| 항목 | 뜻 |
|---|---|
| `slide` | 대상 슬라이드. `"(Insulation)"` 처럼 슬라이드에 있는 문구를 적으면 그 문구와 `shape` 표가 있는 슬라이드를 자동으로 찾습니다. 한 장짜리 PPT 든 전체 PPT 든 같은 설정으로 동작. 숫자를 적으면 그 번호의 슬라이드 |
| `shape` | PPT 표 이름. PowerPoint 에서 **홈 → 선택 → 선택 창** 으로 확인 |
| `sheet` | 엑셀 시트 이름 |
| `month_col` | 엑셀에서 **1월 값이 있는 열**. 오른쪽으로 12개월 → 누적 → N월 누적 순서로 읽음 |
| `ppt_row` | PPT 표의 행 번호 (머리글이 0) |
| `excel_row` | 엑셀 행 번호 |
| `kind` | `fixed` 전년/목표(12개월 모두 표시) · `actual` 실적/달성율(당월까지, 다음 달은 괄호) · `diff` 증감(당월까지만) |
| `label` | 검증용. 엑셀 그 행의 라벨에 이 글자가 없으면 경고 (생략 가능) |
| `fmt` | 생략하면 엑셀 셀 서식으로 판단. `pct`(0.974→97.4%) · `pct_plain`(97.4→97.4%) · `amount`(백만 단위) |

- `excel_row` 가 `null` 인 행은 건너뜁니다.
- `blocks` 항목은 엑셀 직사각형 범위를 PPT 표에 그대로 복사합니다(슬라이드 1). `summary_cells` 는 셀 하나씩 지정합니다(슬라이드 9). 파일 안의 `_설명` 을 참고하세요.
- PPT 차트가 참조하는 시트 이름과 실제 시트 이름이 다르면 `sheet_alias` 에 `"차트의 이름": "실제 이름"` 을 넣으세요.
- 표를 자동화에서 빼려면 그 덩어리에 `"enabled": false` 를 추가하세요.

## 8. 알아 두면 좋은 것

- 결과 PPT의 차트는 여전히 원래 엑셀 파일(J: 드라이브 경로)에 "연결" 상태로 남아 있지만, 값은 이 프로그램이 직접 넣었으므로 연결이 끊겨 있어도 정상 표시됩니다. PowerPoint 에서 "링크 업데이트" 를 묻는 경우 **업데이트 안 함** 을 선택하세요.
- 기준 PPT 는 아무 달 파일이나 써도 됩니다. 값을 모두 새로 덮어쓰고 월 표기도 새 달로 바꿉니다.
- 슬라이드는 번호가 아니라 문구("(Insulation)", "(탈취필터)", "Insulation 노무비" 등)로 찾으므로, Insulation 한 장만 있는 PPT 나 순서가 바뀐 PPT 에도 그대로 쓸 수 있습니다. 해당 문구의 슬라이드가 없으면 그 표는 건너뜁니다.
- 원본 PPT는 건드리지 않고 항상 새 파일로 저장합니다.
